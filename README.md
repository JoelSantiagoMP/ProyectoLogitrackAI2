# Proyecto LogiTrack AI

Aplicación **LogiTrack**: gestión de bodegas, inventario, movimientos, auditoría y reportes.

La implementación Spring Boot está en el directorio [`logitrack/`](logitrack/). Allí encontrarás el README completo (cómo ejecutar, API, esquema SQL y decisiones de diseño).

## Inicio rápido

```bash
cd logitrack
./mvnw spring-boot:run
```

Abre [http://localhost:8080](http://localhost:8080).
